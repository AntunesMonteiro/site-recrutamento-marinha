Site do Recrutamento da Marinha

Este site nasce da necessidade identificada de fazer um novo portal, moderno e mais adaptado ao publico-alvo , que são jovens e adultos interessados em ingressar na Marinha.

Objetivo: 
Informar, orientar e permitir candidatura digital com validação, estado persistente e envio de dados. Isto será possível com páginas informativas, navegação responsiva e aplicações interativas: Teste Psicológico e Candidatura online.

Tecnologias:
- HTML5 e CSS3 (Flexbox, Grid, responsivo)
- JavaScript
- React 18 (Functional Components)
- Redux toolkit (estado global)
- React Router (HashRouter)
- Web Storage API (`localStorage`) – autosave
- fetch API (async/await)
- JSON Server
- GitHub Pages (Deploy estático)
